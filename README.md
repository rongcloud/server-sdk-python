### rc-server-sdk v3.0+ 使用的 Python 3.6+ 版本

python 版本的融云服务端 sdk。

### 安装运行所需的包
```
$ sudo pip3 install jinja2
```

### pip 安装方式
```
$ pip install rc-server-sdk
```

### 包升级
```
$ pip install --upgrade rc-server-sdk
```

### SDK 使用
见目录 unit_test，或 [融云官网文档](https://www.rongcloud.cn/docs/server.html)。
